## Make more with your laser

KizamuBeam is building a friendly, capable open-source ecosystem for laser work. Our tools help turn an idea into a finished piece: create the design, prepare it with confidence, and send it to the machine.

Everything we make is free software, works across macOS, Windows and Linux, and is designed to be useful from a first project to a well-equipped workshop.

## Our projects

| Project | What it is |
| :-- | :-- |
| [**KizamuBeam**](https://github.com/KizamuBeam/kizamubeam) | The desktop app for designing, engraving and cutting. Draw, import artwork, generate parts, preview in 3D and control compatible lasers. |
| [**Extensions & plug-ins**](https://github.com/KizamuBeam/kizamubeam-plugins) | A growing home for add-ons, generators, materials, device presets, templates and community-built tools. |
| [**KizamuBeam Virtual Machine**](https://github.com/KizamuBeam/kizamubeam-vm) | A standalone virtual laser controller for developing, testing and exploring controller behaviour without a physical machine. |

## Built for making

| Create | Prepare | Produce |
| :-- | :-- | :-- |
| Vectors, text, images and parametric parts | Nesting, material and focus tests, 3D preview | Send jobs directly to your laser |
| SVG, DXF, PDF, AI and LightBurn imports | Boxes, gears, joints and slot-together models | USB & Wi-Fi · Rotary · Z axis · Air assist |

KizamuBeam supports FluidNC, GRBL, grblHAL, Marlin and Smoothieware controllers.
